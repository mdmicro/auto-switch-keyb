# Changelog

Все значимые изменения проекта — в этом файле (формат по мотивам
[Keep a Changelog](https://keepachangelog.com/), даты — релизы).
Версия приложения в исходниках: `version.py` (`__version__`).

## 1.5.3 (2026-11-24)

Ручная смена раскладки слова (`Ctrl+Shift+F`) и автоисправление теперь
заменяют слово **целиком** во всех приложениях, включая консоли.

### Исправлено

- **Половина слова оставалась в старой раскладке** (`print ` +
  `Ctrl+Shift+F` → `pзкште` вместо `зкште`). Стирание считалось по длине
  слова из буфера хука, а на экране после слова лежит **хвост**: пробел или
  запятая, которой слово закончили (эти клавиши не съедаются и уходят в
  приложение), автозакрытые скобки/кавычки и автокоррект. Первый `Backspace`
  съедал пробел, слово стиралось **с конца**, и зеркало дописывалось к
  оставшейся начальной букве. Теперь пачка стирает «слово + хвост» и
  печатает хвост обратно: `fixer.replace_last_word(..., tail=...)`,
  `engine.SwitchEngine._screen_tail` (хвост читается из текста у каретки).
- **Стирание вслепую в полях с автодополнением** (браузер, офис,
  мессенджеры, редакторы): `len(word)` `Backspace`'ов там не хватало ровно
  на те символы, которых хук не видел. Добавлены режимы стирания
  (`engine.SwitchEngine._erase_mode`): `word` — `Backspace`'ы по хвосту +
  `Ctrl+Backspace` (приложение стирает «слово до границы», убирая и
  автосимволы); `count` — точное число `Backspace`'ов для нативных
  edit-контролов (`EDIT_CLASSES`: Notepad, Delphi TEdit, RichEdit —
  `Ctrl+Backspace` не понимают, печатают `\x7f`) и для консолей.
- **Консоли (cmd, PowerShell, Windows Terminal, Far, WSL) не поддерживались**:
  `Ctrl+Backspace` в них стирает слово границей (DosKey, PSReadLine) и не
  зависит от длины, `Escape` не шлётся **никогда** (в cmd и PSReadLine он
  очищает ВЕСЬ ввод строки). Консоль определяется по имени процесса
  (`CONSOLE_APPS`, расширяется через `config["console_apps"]`) и по классам
  окон (`password_guard.CONSOLE_WINDOW_CLASSES`). UIA-текст у каретки в
  консоли не запрашивается — `TextPattern` там нет.
- **Исправление в консольном окне больше не печатало «не на месте»**: если
  текст у каретки читается и нашего слова там нет (каретку переставили, поле
  с автодополнением «уехало») — исправление и смена раскладки **пропускаются**
  (раньше `Backspace`'ы съедали чужой текст и на экране оставалась смесь
  раскладок).
- **Смена раскладки слова для слова «на лету»**: если слово не закончено
  пробелом (хоткей нажали, печатая слово), слово берётся из текста перед
  кареткой (`engine.SwitchEngine._word_at_caret`).
- **Откат (`Ctrl+Z`) после `Enter`/`Tab` не выполняется** и передаётся
  приложению: посимвольно стереть перевод строки надёжно нельзя (в нативных
  edit он занимает 2 символа, в консоли `Enter` исполняет команду).
- **Двойной запуск программы блокируется** (`auto_switch_keyb.py`:
  именованный мьютекс `Local\AutoSwitchKeyb.single.instance`). Две копии =
  два глобальных хука на одном вводе: обе стирают и печатают последнее слово,
  вторая печатает поверх результата первой — на экране смесь раскладок.

### Добавлено

- `console_apps` в `config.json` (seed-список пустой) — дополнительные
  процессы-консоли; в окне «Настройки» не настраивается.
- `password_guard.focused_text_before_caret` — чтение текста перед кареткой
  через UIA `TextPattern` (кэш `TEXT_TTL = 0.35` с, короткое окно жизни:
  вызовы идут из хука); `focused_window_classes` — классы активного окна и
  контрола фокуса.
- `test_e2e_edit.py` — E2E на реальном контроле ввода: `EDIT` (режим
  `count`) и `RICHEDIT50W` (режим `word`), включая регрессию исходного бага
  (`print ` → `pзкште`). Перед каждым посылом клавиш проверяется фокус:
  не наш — клавиши не шлются.

## 1.5.2 (2026-11-14)

### Исправлено

- Окно «Настройки» при **повторном** открытии показывало пустые поля
  (значения из `config.json` «не подгружались»). tk-переменные окна
  создавались без `master` и привязывались к глобальному
  `tk._default_root` — интерпретатору первого окна; после его закрытия
  интерпретатор мёртв, `.set()` писал в него, а виджеты нового окна
  значений не видели. Теперь все переменные окна создаются с
  `master=`, и каждое окно работает со своим интерпретатором.
- Тест повторного открытия (сохранить → закрыть → открыть заново →
  проверить заполнение) покрывает сценарий.

## 1.5.1 (2026-11-14)

### Исправлено

- Окно «Настройки» (с 1.5.0): панель кнопок «Сохранить и применить» /
  «По умолчанию» / «Отмена» схлопывалась в невидимую полоску (1 px),

  перечитывание config.json -> refresh_now движка) покрывает этот сценарий.

## 1.5.0 (2026-11-13)

Ручная смена раскладки последнего набранного слова.

### Добавлено

- Горячая клавиша **смены раскладки последнего слова** (по умолчанию
  `Ctrl+Shift+F`, настраивается) — как в Punto Switcher: перепечатывает
  последнее набранное слово «зеркалом» по физическим клавишам и
  переключает раскладку на язык результата. В отличие от автокорректора,
  слово не обязано быть «мусорным» — меняется и словарное (`print` →
  `зкште`, `привет` → `ghbdtn`).
- Условие срабатывания: слово закончено (пробел/Enter/пунктуация), после
  него ничего не печатали и не стирали; в полях паролей не выполняется;
  результат откатывается отменяющим хоткеем (Ctrl+Z).
- В окне «Настройки» — второй блок хоткеев (модификаторы + клавиша) для
  этой клавиши, с заполнением, «По умолчанию» и валидацией.
- Ключ конфига `switch_hotkey` (в seed-файл config.json и DEFAULT_CONFIG).
- Юнит-тесты смены раскладки слова (замена, откат, отказы), интеграционный
  тест окна с двумя блоками хоткеев.

## 1.3.0 (2026-11-11)

Защита полей пароля и авторизации от автоисправления.

### Добавлено

- Поля ввода пароля/авторизации теперь исключаются из исправления по
  умолчанию (и это не отключается в настройках — намеренно): движок не
  трогает скрытый ввод, чтобы не портить пароль «не той раскладкой» и
  не показывать его перепечаткой на экране.
- Определение поля пароля в момент предполагаемого исправления
  (`password_guard.py`), два уровня:
  - UI Automation `IsPassword` — браузеры (Chromium/Gecko), Electron,
    WPF, WinUI — весь современный UI;
  - нативные edit-контролы по стилю `ES_PASSWORD` (Win32, Delphi/Builder,
    RichEdit) — быстрый фолбэк без COM.
- Если проверка не удалась (нет UIA и т. п.), исправление разрешается:
  guard не может ломать основную функцию программы.
- Тест `test_password_guard.py`: нативные EDIT (с `ES_PASSWORD`/без) и
  реальные страницы Edge (app-режим, локальные html, без набора текста).

### Изменено

- `requirements.txt`, `build_exe.ps1`: добавлен `comtypes`
  (UI Automation), тип библиотека UIA предгенерируется на сборке.

## 1.0 (2026-11-08)

Первый релиз.

### Ядро

- Глобальный хук `WH_KEYBOARD_LL`: сбор слова, зеркальная эвристика RU↔EN,
  исправление одной атомарной пачкой `SendInput` («Backspace'ы + слово +
  терминатор») со «съеданием» клавиши-терминатора.
- Исправление работает во всех приложениях, включая консоль
  (cmd/PowerShell/терминал VS Code).
- Собственный ввод помечается magic-значением `dwExtraInfo` и не
  самоисправляется.
- Защита от разъезда каретки, обработка `VK_PACKET` (Unicode-ввод),
  фолбэки `GetKeyboardLayout` для консоли.

### UI

- Иконка в трее — флаг текущей раскладки (RU/EN, серый перечёркнутый при
  выключении), перекрашивается при смене раскладки, включая ручную
  (Alt+Shift, Ctrl+Shift, Win+Space, Caps Lock).
- Меню: вкл/выкл, смена раскладки, «Настройки…», автозапуск (HKCU Run), выход.
- Окно «Настройки»: горячая клавиша отмены (модификатор + буква/цифра,
  одиночные F1–F12), список приложений-исключений с кнопкой «Навести окно…»,
  переключатель локального лога; применение без рестарта (hot-reload).
- Горячая клавиша отмены (`Ctrl+Z` по умолчанию) с семантикой: откат
  последнего фикса, только если после него ничего не набрано.

### Инфраструктура

- Словари: RU 260 000 (danakt/russian-words) + EN 170 000
  (dwyl/english-words), фильтр по длине, готовый JSON в репо.
- Конфиг `config.json` и лог `log.txt` в каталоге данных приложения
  (автоповорот лога 512 КБ).
- Сборка EXE: `build_exe.ps1` (Nuitka 4.3.4, onefile, без консоли) с обходом
  бага MSVC `C2086`.
- Тесты: движок (`test_engine.py`), корректор (`test_corrector.py`),
  e2e-скрипты для живых проверок.

### Исправления по ходу разработки

- `INPUT.union` без MOUSEINPUT → `SendInput` 0 (err 87) — исправлено.
- Гонка каретки при посимвольном вводе — переход на атомарную пачку.
- `WM_INPUTLANGCHANGEREQUEST` без смены языка ломал ввод в терминале —
  смена раскладки только при реальном RU↔EN.
- Консоли убраны из исключений по умолчанию (исправление и в терминале).
- Поток обновления иконки умирал до `icon.run()` (`while icon.visible:`) —
  исправлено, плюс мгновенная реакция на Win+Space.
