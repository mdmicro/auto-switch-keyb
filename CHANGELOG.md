# Changelog

## 1.0 (2026-11-08)

Первый релиз.

### Ядро

- Глобальный хук `WH_KEYBOARD_LL`: сбор слова, зеркальная эвристика RU↔EN,
  исправление одной атомарной пачкой `SendInput` («Backspace'ы + слово +
  терминатор») со «съеданием» клавиши-терминатора.
- Исправление работает во всех приложениях, включая консоль
  (cmd/PowerShell/терминал VS Code).
- Собственный ввод помечается magic-значением `dwExtraInfo` и не
  самоисправляется.
- Защита от разъезда каретки, обработка `VK_PACKET` (Unicode-ввод),
  фолбэки `GetKeyboardLayout` для консоли.

### UI

- Иконка в трее — флаг текущей раскладки (RU/EN, серый перечёркнутый при
  выключении), перекрашивается при смене раскладки, включая ручную
  (Alt+Shift, Ctrl+Shift, Win+Space, Caps Lock).
- Меню: вкл/выкл, смена раскладки, «Настройки…», автозапуск (HKCU Run), выход.
- Окно «Настройки»: горячая клавиша отмены (модификатор + буква/цифра,
  одиночные F1–F12), список приложений-исключений с кнопкой «Навести окно…»,
  переключатель локального лога; применение без рестарта (hot-reload).
- Горячая клавиша отмены (`Ctrl+Z` по умолчанию) с семантикой: откат
  последнего фикса, только если после него ничего не набрано.

### Инфраструктура

- Словари: RU 260 000 (danakt/russian-words) + EN 170 000
  (dwyl/english-words), фильтр по длине, готовый JSON в репо.
- Конфиг `%LOCALAPPDATA%\punto_switch\config.json`, лог `log.txt`
  с автоповоротом 512 КБ.
- Сборка EXE: `build_exe.ps1` (Nuitka 4.3.4, onefile, без консоли) с обходом
  бага MSVC `C2086`.
- Тесты: движок (`test_engine.py`), корректор (`test_corrector.py`),
  e2e-скрипты для живых проверок.

### 1.0.1 (2026-11-08)

- Конверсия клавиш в символы — `ToUnicodeEx` с раскладкой фокусного окна
  (`GetKeyboardState`/`ToUnicode` берут раскладку потока-установщика хука и
  «зеркалили» буквы заранее: направление «русская раскладка → английское
  слово» молча не исправлялось).
- Окно «Настройки» в EXE: добавлен плагин Nuitka `tk-inter` — без него в
  onefile-сборке нет `tcl\init.tcl`, `tk.Tk()` падал, исключение в потоке
  убивало иконку трея молча, и автоисправление останавливалось.
- Пункты меню и окно настроек обёрнуты в `_menu_guard`: падение теперь
  пишется в лог и не роняет приложение.
- Ключ `debug` в `config.json`: подробная диагностика слов и хоткея в
  `log.txt` (по умолчанию выключен).
- `save_config` объединяет настройки с уже записанными, а не перезаписывает.

### Исправления по ходу разработки

- `INPUT.union` без MOUSEINPUT → `SendInput` 0 (err 87) — исправлено.
- Гонка каретки при посимвольном вводе — переход на атомарную пачку.
- `WM_INPUTLANGCHANGEREQUEST` без смены языка ломал ввод в терминале —
  смена раскладки только при реальном RU↔EN.
- Консоли убраны из исключений по умолчанию (исправление и в терминале).
- Поток обновления иконки умирал до `icon.run()` (`while icon.visible:`) —
  исправлено, плюс мгновенная реакция на Win+Space.
