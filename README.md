# Auto Switch Keyb

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue)](#быстрый-старт)
[![Python](https://img.shields.io/badge/python-3.9%2B-informational)](https://www.python.org/)
[![Telegram](https://img.shields.io/badge/Telegram-%40mdmdev-blue?logo=telegram)](https://t.me/mdmdev)

Автоматический переключатель раскладки клавиатуры **RU ↔ EN** — аналог
[Punto Switcher](https://puntoswitcher.com/) на чистом Python для Windows 10/11.
Версия: `1.3.2` (`version.py`, история изменений — [CHANGELOG.md](CHANGELOG.md)).

Если вы набрали слово «в не той раскладке» (`ghbdtn` вместо `привет`),
Punto Switcher стирает его, печатает правильное слово и переключает
раскладку на язык результата. Всё локально, без интернета.

```
ghbdtn cbvf print        ← набрали в EN
привет сима print        ← получилось на экране
```

## Иконка в трее

| RU | EN | выключено |
|---|---|---|
| ![ru](docs/img/tray_ru.png) | ![en](docs/img/tray_en.png) | ![off](docs/img/tray_off.png) |

Флаг = текущая раскладка; перекрашивается при печати и при ручном
переключении (Alt+Shift, Ctrl+Shift, Win+Space, Caps Lock).

## Возможности

- 🌐 Глобальная работа во всех приложениях — браузер, офис, мессенджеры,
  терминал (консоль **не** исключается).
- 🏳️ Иконка в трее — **флаг текущей раскладки** (RU — триколор, EN —
  юнион-джек), мгновенно перекрашивается при смене раскладки, в том числе
  вручную (Alt+Shift, Ctrl+Shift, Win+Space, Caps Lock).
- ↩️ Горячая клавиша **отмены** последнего исправления (по умолчанию
  `Ctrl+Z`; назначается своя).
- ⚙️ Окно «Настройки»: назначение хоткея отмены, список приложений-исключений
  (с кнопкой «навести окно…»), применение без рестарта.
- 🚀 Автозапуск при входе в Windows (одна галочка в меню трея).
- 🔒 **Поля паролей/авторизации не трогаются** — определяются автоматически,
  независимо от списка исключений (см. [Безопасность](#-безопасность)).
- 🔒 **Никакой сети и телеметрии.** Ни один символ не покидает машину
  (см. [Безопасность](#-безопасность)).
- 📦 Один EXE-файл (Nuitka), словари в комплекте.

## Быстрый старт

### Вариант 1 — готовый EXE

Скачайте `auto-switch-keyb.exe` из [releases](../../releases), положите в папку,
где рядом будут лежать `words/` и `config.json` (весь архив releases уже
так устроен), и запускайте двойным кликом. На первый запуск Windows может
показать SmartScreen для неподписанного файла — «Подробнее → Выполнить».

### Вариант 2 — из исходников

Нужен Python 3.9+ (проверено на 3.10) и Windows.

```bat
py -3.10 -m pip install -r requirements.txt
py -3.10 auto_switch_keyb.py
```

Готовые словари (`words/words_*.json`) лежат в репозитории — программа
запустится сразу. Если хотите перестроить их из полных списков слов — см.
[Словари](docs/ARCHITECTURE.md#словари) и `py -3.10 build_words.py`.

Для запуска без окна консоли — `start.bat`.

## Использование

После запуска в трее появляется флаг раскладки. Правый клик — меню:

| Пункт | Действие |
|---|---|
| ✔ Включено | вкл/выкл автоисправление (выключено — флаг серый и перечёркнут) |
| Русская / Английская раскладка | сменить раскладку активного окна |
| **Настройки…** | окно настроек |
| Автозапуск | запускать при входе в Windows (HKCU\...\Run) |
| Выход | остановить и выйти |

### Отмена исправления

`Ctrl+Z` (назначается своя комбинация) откатывает **последнее** автоматическое
исправление: стирает исправленное слово, печатает исходное и возвращает
раскладку набора. Откат срабатывает, только если после исправления вы не
напечатали ни символа — иначе `Ctrl+Z` проходит приложению как обычная
«отменить».

### Окно «Настройки»

- горячая клавиша отмены: модификаторы (Ctrl/Shift/Alt) + буква/цифра,
  либо одиночная F1–F12;
- приложения, в которых автоисправление **не работает** — можно ввести имя
  exe, а можно нажать «Навести окно…», и в список добавится процесс
  активного окна;
- запись исправлений в локальный лог (по умолчанию включена);
- «Сохранить и применить» — движок подхватывает настройки **без рестарта**.

В исключениях по умолчанию только `logonui.exe` и `credentialui.exe`
(экран входа и окна учётных данных).

## Сборка EXE (Nuitka)

```powershell
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```

Получится `dist\auto-switch-keyb.exe` (onefile, без консоли, ~18 МБ); рядом
скрипт кладёт словари и seed-`config.json`. Подробности, требования к
компилятору и обход бага Nuitka 4.3.4 — в [docs/BUILD.md](docs/BUILD.md).

## Как это работает (кратко)

1. Глобальный хук `WH_KEYBOARD_LL` слушает клавиатуру и собирает «текущее слово».
2. На границе слова (пробел/Enter/Tab/пунктуация) строится его **зеркало** —
   те же нажатия клавиш в другой раскладке.
3. Слово исправляется, только если зеркало есть в словаре, а набранное — нет
   (и слово не смешанное, не короткое, и не в исключённом приложении).
4. Исправление отправляется **одной атомарной пачкой** `SendInput`
   («Backspace'ы + слово + терминатор»), а клавишу-терминатор хук «съедает»,
   поэтому каретка не разъезжается. Собственный ввод помечается magic-значением
   `dwExtraInfo` и хуком игнорируется.

Полное описание — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## 🔒 Безопасность

- **Ноль сетевых вызовов.** В коде нет socket/http/requests/urllib —
  проверка: `grep -r "socket\|http\|urllib\|requests\|urlopen" *.py` пуста.
  Обработка и словари — только локально.
- На диск пишется лишь локальный лог: `%LOCALAPPDATA%\auto-switch-keyb\log.txt`
  (только **исправленные слова**, не весь ввод; отключается в настройках)
  и `config.json` там же.
- Буфер обмена не используется.
- **Поля паролей и авторизации исключаются из исправления всегда** (не
  отключается в настройках): определяются по UI Automation `IsPassword`
  (браузеры, Electron, WPF) и по стилю `ES_PASSWORD` нативных edit-контролов;
  скрытый ввод не стирается и не перепечатывается.

## ⚠️ Ограничения

- Словарь покрывает не всё: имена, жаргон, опечатки внутри слова не исправляются.
- Исправление работает там, где печать идёт «в конец» поля (текстовые поля,
  редакторы). Поля с агрессивным автодополнением могут мешать.
- Поддерживаются только RU ↔ EN (ЙЦУКЕН ↔ QWERTY).
- Слово должно быть закончено пробелом/Enter/Tab — правок внутри строки нет.

## Конфигурация

`%LOCALAPPDATA%\auto-switch-keyb\config.json` (создаётся сам из seed-файла):

```json
{
  "undo_hotkey": "ctrl+z",
  "excluded_apps": ["logonui.exe", "credentialui.exe"],
  "log_fixes": true
}
```

## Структура проекта

```
auto_switch_keyb.py точка входа
version.py         версия приложения и отображаемое имя
engine.py          глобальный хук, распознавание, хоткей отмены, хот-релоад конфига
corrector.py       словари + эвристика «зеркального» слова
layout_map.py      соответствие клавиш RU/EN
fixer.py           SendInput: атомарная замена слова, смена раскладки
tray.py            иконка-флаг в трее, меню, автозапуск
settings.py        окно «Настройки» (Tkinter)
hotkey_config.py   чтение/запись config.json, парсинг хоткеев
paths.py           пути к данным (исходники / Nuitka EXE)
flags.py           иконки-флаги (рисуются кодом, PIL)
build_words.py     сборка словарей из words/*_raw.txt
build_exe.ps1      сборка EXE (Nuitka onefile)
test_*.py          тесты движка и корректора
words/             словари (готовые .json в репо; *_raw.txt — по ссылкам ниже)
```

Источники списков слов (перестроение — `py -3.10 build_words.py`):

- RU: [danakt/russian-words](https://github.com/danakt/russian-words) → `words/ru_raw.txt`
- EN: [dwyl/english-words](https://github.com/dwyl/english-words) (`words_alpha.txt`) → `words/en_raw.txt`

## Тесты

```bat
py -3.10 test_engine.py        # движок: хук-логика, фиксы, откат (без GUI)
py -3.10 test_corrector.py     # корректор и словари
```

E2E-тесты, которые реально шлют клавиши в Блокнот (`test_e2e.py` и компания),
запускайте **когда вы не работаете за машиной**: они печатают с клавиатуры,
и ваши окна-конкуренты перехватят ввод.
