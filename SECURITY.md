# Безопасность

## Что делает приложение с вашими данными

- Клавиатуру слушает глобальным низкоуровневым хуком, обрабатывает посимвольно
  и целиком локально: набираемое слово проверяется по локальным словарям,
  ничего не сохраняется.
- Сетевых вызовов в коде нет вообще: ни `socket`, ни `http`, ни `urllib`,
  ни `requests`, ни `urlopen`. Проверка:

  ```powershell
  Select-String -Path *.py -Pattern "socket|http|urllib|requests|urlopen|ftplib|smtplib"
  ```

  Совпадений нет (исключение — упоминание URL в комментариях и docstrings
  про источники словарей).
- На диск приложение пишет ровно два файла, оба в `%LOCALAPPDATA%\punto_switch\`:
  - `config.json` — ваши настройки (хоткей, исключения, флаг лога);
  - `log.txt` — журнал исправлений: только **исправленные слова**, не весь
    ввод (отключается галочкой в «Настройках», автоповорот при 512 КБ).
- Буфер обмена приложение не читает и не пишет.
- Словари — обычные локальные JSON-файлы рядом с программой.

## Защита от перехвата ввода

- Глобальный хук видит ваши нажатия — это и есть его работа: он не может
  исправлять раскладку, не видя клавиш. Данные никуда не пересылаются.
- Хук ставится на уровне текущего пользователя, не требует администратора
  и не работает в окнах с более высоким integrity level (экран входа и
  окна учётных данных — в исключениях по умолчанию).
- Приложение запускается от вашего имени и пишет только в `%LOCALAPPDATA%`.
